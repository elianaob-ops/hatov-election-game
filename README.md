# הטוב בהתגלמותו

עותק עצמאי של משחק ניחושי המנדטים, לקהילת הטוב בהתגלמותו. שם הקלפי: הקלפי של הטוב בהתגלמותו. הדמויות וכללי המשחק נשארו כפי שהיו. 0 נבחר באמצעות הכפתור ״מתחת לאחוז החסימה״; בתפריט בוחרים 4–120 מנדטים, וסך ההקצאה חייב להיות 120 בדיוק. ניחושי אחרים נחשפים רק לאחר הנעילה.

שם האתר עודכן בכותרת הדפדפן, בכותרת העליונה, במסכי הכניסה, בהודעות ההצטרפות, במסך הניהול, בפרופיל הניהול ובשם ברירת המחדל לקלפי. מנהלת האישור נשארה אליענה. מועד הנעילה נשאר 27.10.2026 בשעה 06:59, שעון ישראל. התמונה הקבוצתית שסופקה משמשת כאייקון האתר, כתמונה בכותרת וכאייקון במסך ההמתנה לאישור. קובץ התמונה המקורי נשמר ללא שינוי; ההתאמה לתצוגה נעשית בעיצוב העמוד.

## פריסה חדשה ונפרדת

1. יש ליצור מאגר GitHub חדש ולהעלות אליו את קבצי התיקייה הזאת בשורש המאגר. אין להעלות אותם למאגר או לשירות Render של דבי פוליטי.
2. צרו שירות Web Service חדש ב־Render, בשפת Docker, וחברו למאגר החדש. Root Directory יישאר ריק כשהקבצים בשורש המאגר. Dockerfile שבתיקייה הזאת הוא מלא ועצמאי, ללא תיקיות העדכון המקוננות של המאגר הישן.
3. הגדירו COMMUNITY_ADMIN_USER בשם משתמש ניהול אישי ו־COMMUNITY_ADMIN_PASSWORD בסיסמה אישית של לפחות 12 תווים. אל תשלחו סיסמה בצ׳אט ואל תעלו אותה למאגר.
4. הגדירו דיסק נפרד לשירות החדש, מותקן ב־/data, ו־DB_PATH=/data/game.sqlite. הקוד אינו כולל מסד נתונים, חשבונות, אישורים, תמונות משתתפים או ניחושים מהקהילה המקורית. אל תעתיקו קובץ SQLite מהשירות המקורי.
5. לאחר הפריסה, היכנסו לחשבון הניהול בכתובת החדשה. אישורי המשתתפים נמצאים ב־/members. יש לשתף עם הקהילה את הכתובת החדשה בלבד.

טרם בוצעה פריסה או התחייבות לתשלום. השירות והדיסק החדשים מחויבים בנפרד לפי המסלול שתבחרו ב־Render.

## פיתוח

נדרש Node.js 24 ומעלה, עם SQLite מובנה. הגדירו את משתני הניהול ו־DB_PATH למסד בדיקה, ואז הריצו npm start. בדיקות השרת: npm test. בדיקות הממשק: npm ci ואחריו npm run test:ui. בדיקות jsdom אינן בדיקת צילום חזותית בדפדפן.
